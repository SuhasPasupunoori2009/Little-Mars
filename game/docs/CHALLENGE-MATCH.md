# How Little Mars matches the challenge brief

The requirements below are our team's summary of the Space Apps brief (kept in `PRODUCT.md`). Check each row against the official challenge text before submitting; we have not pasted the official wording here.

| Brief asks for | Where it is in the game |
|---|---|
| Browser game for ages 7 to 12 | Single `index.html`, no install or account. Age picker sets camp, missions and Pip's help. Large touch targets; text size, high contrast, reduced motion. |
| Real NASA open data, attributed inside the tool | NASA CCMC DONKI flares, solar particle events and CMEs drive every sol. Source, retrieval date and link are in the forecast, "Real NASA science" and "About the data". |
| Static versus live data labelled honestly | Forecast label reads STATIC ARCHIVE (with retrieval time) or LIVE (with fetch time). Live is opt-in. The archive is described as curated, and eased days are flagged. |
| Game interpretation separated from NASA data | "NASA observation vs. game interpretation" appears beside the forecast and in About the data: Calm, Watch and Storm are game levels, not NASA warnings. |
| Real trade-offs with a handful of core resources | Air, Food, Power, Safety (radiation). Every job costs power, air, time and often Safety, more on stormy days. |
| Replayability | 148 real weeks, random Mars events, easy/normal/hard, two camp styles, level unlocks, expert missions, badges that turn silver and gold. |
| Learning outcome | Warm-up and science check use the same four questions so a before/after can be seen. Teacher guide has a lesson plan and answer key. |
| Space weather and radiation on Mars | Shelter, Safety meter, Curiosity May 2024 radiation event, 20-minute radio delay (NASA range 3 to 22 minutes). |
| v3: decisions under pressure | Mission alerts show every cost before the choice, always include a no-cost option, and are logged. |
| v3: science you can try | Five lab experiments, a research tree whose items change game rules, and a science report at the end. |
| v3: data shown, not hidden | Sun dashboard puts NASA's flare class, CME speed and particle events next to the game's level for each sol, with source and time. |
| Not used | NASA OSDR (space biology) is listed as future work, not claimed. |

Limits: the game pretends each day's Sun event hits Mars the same day; Safety is a teaching meter, not a dose; score weights are teaching choices. All three are stated in the game.
