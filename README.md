# MarsSurvivor
Mars Survivor is an interactive Martian outpost simulator where users manage four astronauts over a 30-day mission. Manage oxygen, water, food, power and radiation protection while responding to Mars environmental challenges. Explore the engineering and resource-management challenges of sustaining human life on Mars.


## Little Mars: Storm Watch

A browser game for ages 7 to 12 about space weather, built on real NASA DONKI records. NASA Space Apps 2026 entry.

**Play:** open the GitHub Pages site for this repository, or download `index.html` and double-click it. It is one file and works offline.

- The default weeks come from a saved copy of NASA DONKI (2024-01-01 to 2025-10-31). Live data is optional and falls back to the saved copy.
- Game rules simplify the science. Labels in the game say what is a NASA observation and what is a game simplification.
- Source is in `game/source` (build with `python build.py`), docs in `game/docs`.
- Not yet playtested with children.
